# Kymation flat model reserve

This folder preserves rejected Kymation images whose ring profile reads as a flat band instead of the approved beveled edge profile.

## Rejection rule

- The approved Kymation profile has a broad satin center.
- One continuous fine milgrain border sits on each side of the center.
- A clearly sloped, mirror-polished planar bevel sits outside each milgrain border.
- A polished vertical rail without a visible sloped shoulder is not sufficient.

## Reserved roles

The original `03-side.jpg` and `04-top.jpg` files from all nine metal and karat listings are preserved here. These files must not be reused for Kymation. They may be reviewed as source material for a separate flat profile model.

See `manifest.csv` for listing and Etsy identifiers.
