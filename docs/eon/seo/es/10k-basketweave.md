## Üretim notu

BLOKE EDEN KALINLIK ÇELİŞKİSİ KANITLA ÇÖZÜLDÜ → 1.5mm yazıldı. Kanıt (varsayım değil, DB ölçümü): aynı genişlik+beden çiftlerinde basketweave/dome ağırlık oranı 6MM-4 1.372 / 6MM-10 1.364 / 8MM-9 1.363 / 10MM-10 1.365 — dört çiftte SABİT. Dome'un kendi canlı EN metni '1.5mm thick' diyor. Sabit 1.365 oranı yalnızca PROFİL geometrisiyle açıklanıyor (biselli düz kesit ~0.91·w·t, dome dairesel segment ~0.667·w·t → 0.91/0.667 = 1.365, eşit kalınlıkta). Basketweave 2.0mm olsaydı oranın üstüne 2.0/1.5 = 1.333 çarpanı binerdi (~1.82 beklenirdi); gözlenmiyor. Ayrıca second-brain'deki EON v2→v3 dönüşümü 2.0mm'yi katalogdan KALDIRMIŞTI. Sonuç: canlı EN'deki 'Widths: 6mm to 10mm, 2mm thick' BAYAT metin.
